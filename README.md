# ระบบติดตามภาระงานและการส่งงานบุคลากร สกร.อำเภอเมืองหนองบัวลำภู

เว็บไซต์สำหรับมอบหมายงานตามตัวชี้วัด แยกตามกลุ่มงาน บันทึกผลการส่งงานและคะแนน และออกรายงานภาระงานรายปีงบประมาณ

- หน้าเว็บ: GitHub Pages (ไฟล์ `index.html`, `config.js`, `js/api.js`)
- ฐานข้อมูล: Google Sheets + Google Apps Script (ไฟล์ `apps-script/Code.gs`)
- ไฟล์แนบเอกสารต้นเรื่อง: เก็บใน Google Drive ของผู้ติดตั้ง

## เกณฑ์คะแนน (แก้ไขได้ในแท็บ “ตั้งค่า”)
| ผลการส่งงาน | คะแนน |
|---|---|
| ส่งครบ ตรงเวลา | 1 |
| ส่งไม่ครบ / ไม่ตามกำหนด | 0.5 |
| ส่งล่าช้า | 0 |
| ละเลย / ไม่ส่ง | -1 |

## ติดตั้ง (ทำครั้งเดียว ประมาณ 10 นาที)

### ขั้นที่ 1 สร้างฐานข้อมูล (Google Sheets)
1. เข้า https://sheets.new สร้างชีตใหม่ ตั้งชื่อ เช่น “ฐานข้อมูลภาระงานบุคลากร”
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจากไฟล์ `apps-script/Code.gs` → กดบันทึก
4. เลือกฟังก์ชัน **setup** ที่แถบด้านบน → กด **เรียกใช้** → อนุญาตสิทธิ์ (ถ้าขึ้นว่า “Google ไม่ได้ยืนยันแอปนี้” ให้กด “ขั้นสูง” → “ไปที่…”)
5. ดู **บันทึกการดำเนินการ** ด้านล่าง จะเห็น **รหัสผู้ดูแลระบบ** จดเก็บไว้
   - ระบบใส่รายชื่อบุคลากร 47 คน เกณฑ์คะแนน และปีงบประมาณปัจจุบันให้แล้ว

### ขั้นที่ 2 เปิดเป็นเว็บแอป (API)
1. กด **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
2. รูปเฟือง → เลือก **เว็บแอป**
3. ดำเนินการในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
4. กด **ทำให้ใช้งานได้** → คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

### ขั้นที่ 3 ใส่ URL ในเว็บไซต์
1. ใน GitHub เปิดไฟล์ `config.js` → กดรูปดินสอ (แก้ไข)
2. วาง URL ระหว่างเครื่องหมายคำพูด: `API_URL: "https://script.google.com/macros/s/.../exec",`
3. กด **Commit changes**

### ขั้นที่ 4 เปิด GitHub Pages
1. ใน repository → **Settings → Pages**
2. Source: **Deploy from a branch** · Branch: **main** · โฟลเดอร์ **/ (root)** → Save
3. รอ 1–2 นาที จะได้ลิงก์เว็บไซต์ เช่น `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## การใช้งาน
- **ทุกคน** เปิดลิงก์เว็บไซต์ดูตารางคะแนน งานและผู้รับผิดชอบ และรายงานประจำปีได้
- **ผู้ดูแลระบบ** กด “เข้าสู่ระบบผู้ดูแล” ใส่รหัส → เพิ่มตัวชี้วัด/งาน นำเข้าจากไฟล์ เลือกผู้รับผิดชอบ ให้คะแนน แนบเอกสารต้นเรื่อง
- ข้อมูลที่อ่านง่ายจะอัปเดตอัตโนมัติในชีต “บุคลากร”, “ตัวชี้วัด”, “งานและผู้รับผิดชอบ” (อย่าแก้ชีต `_data` ด้วยมือ)

## เปลี่ยนรหัส / จำกัดคนดู
Apps Script → **การตั้งค่าโปรเจ็กต์** (รูปเฟือง) → **คุณสมบัติของสคริปต์**
- `ADMIN_PASSWORD` รหัสผู้ดูแลระบบ
- `VIEW_PASSWORD` (ไม่บังคับ) ถ้าตั้งไว้ ผู้เปิดเว็บต้องใส่รหัสนี้ก่อนดูข้อมูล

## เมื่อแก้โค้ด Code.gs ภายหลัง
ต้องกด **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (ดินสอ) → เวอร์ชัน: ใหม่ → ทำให้ใช้งานได้** URL เดิมจะยังใช้ได้
